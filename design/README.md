# Design boards

Static copies of the NotchForge Interface boards from Claude Design
(Pinned · Now Playing, Pinned · Overview, Hover · glance, Peek), filled with
the boards' sample data. CI renders them in Chrome on macOS, the boards' font
stack resolving to SF Pro as it does in the app, and prints them next to the
app's own renders of the same content (`07*-notched-*` in the self-test) so the
two can be compared pixel for pixel.
